# 12-Week Interview Plan

**Goal:** Be interview-ready in 12 weeks with ~2.5–3 hours/day, 6 days/week.

Target:

* ~150 well-understood problems
* Strong command of common patterns
* 4–6 mock interviews
* Regular revision
* C++ as the interview language

---

## Week 1 — Arrays, Hashing, Strings Basics

Topics: `vector`, array traversal, `unordered_set`, `unordered_map`, frequency counting, value-to-index mapping, basic strings, two-pointer intro, prefix/suffix basics.

Target: **10 main problems**

## Week 2 — Two Pointers and Sliding Window

Topics: left/right pointers, fast/slow pointers, fixed-size windows, variable-size windows, character-frequency windows.

Target: **12–14 problems**

Core: Two Sum II · 3Sum · Container With Most Water · Best Time to Buy and Sell Stock · Longest Substring Without Repeating Characters · Permutation in String · Longest Repeating Character Replacement

## Week 3 — Stack and Binary Search

Topics: stack basics, monotonic stack, standard binary search, rotated arrays, binary search on the answer.

Target: **12–14 problems**

Core: Valid Parentheses · Min Stack · Daily Temperatures · Binary Search · Search a 2D Matrix · Koko Eating Bananas · Search in Rotated Sorted Array

## Week 4 — Linked Lists

Topics: nodes and pointers, traversal, reversing links, fast/slow pointers, dummy nodes, merging lists.

Target: **10–12 problems** · Core: Reverse Linked List · Merge Two Sorted Lists · Linked List Cycle · Reorder List · Remove Nth Node From End · Add Two Numbers · Copy List With Random Pointer

> By end of Week 4: ~45–50 problems completed.

## Week 5 — Trees and Binary Search Trees

Topics: DFS, BFS, recursion, tree traversals, height/depth/diameter, BST properties, lowest common ancestor.

Target: **15–18 problems**

## Week 6 — Heaps and Backtracking

Topics: min/max heap, `priority_queue`, top-K pattern, subsets, permutations, combinations, choose-explore-undo.

Target: **12–15 problems**

## Week 7 — Graphs

Topics: adjacency lists, BFS/DFS, grid traversal, connected components, cycle detection, topological sort, union-find basics.

Target: **14–16 problems**

## Week 8 — 1-D Dynamic Programming

Topics: recursion, memoization, tabulation, state and transition, space optimization.

Target: **12–15 problems**

> By end of Week 8: ~105–120 problems completed.

## Week 9 — Greedy, Intervals and Tries

Topics: greedy decisions, interval sorting, merge/insert intervals, meeting-room problems, trie operations.

Target: **12–15 problems**

## Week 10 — 2-D DP, Bit Manipulation and Math

Topics: grid DP, longest common subsequence, knapsack-style DP, XOR, bit counting, matrix traversal, basic math patterns.

Target: **12–15 problems**

## Week 11 — Full Revision

No heavy new learning. Each day: re-solve two Yellow/Red problems, solve one unseen medium, review one major pattern, do a timed session, explain solutions aloud.

Focus: hashing · two pointers · sliding window · binary search · linked lists · trees · graph traversal · basic DP

## Week 12 — Interview Simulation

Daily: one easy in 15 min, one medium in 35 min, explain aloud, state complexity + edge cases, review one weak area.

Complete: 4–6 mock interviews · resume walkthrough · project explanations · behavioral prep · mixed sets

---

## Interview Readiness Milestones

**After 4 weeks:** basic online assessments, easy questions, some medium array/hashing/linked-list problems.

**After 8 weeks:** most common internship/new-grad questions, easy+medium across major topics, basic tree/graph/DP discussions.

**After 12 weeks:** ready to apply and interview for full-time roles, provided you can:

* Solve most common easy problems independently
* Solve familiar medium patterns in 30–40 min
* Explain brute force and optimal approaches
* State time and space complexity
* Write clean C++ without syntax help
* Communicate while coding

# Week 1 — Day-by-Day Plan

## Day 1 — Vectors and Sets  ✅ done

Learn: `vector<int>`, indexing, `.size()`, `push_back()`, range-based loops, `unordered_set`, basic Big-O.
Warm-ups: print vector, sum vector, maximum in vector, copy vector.
Main problems:

1. Concatenation of Array — **Green**
2. Contains Duplicate — **Yellow**

## Day 2 — Unordered Map  ✅ done

Learn: key-value pairs, frequency maps, character frequency, number-to-index maps, `count()` vs `[]`, `.first`/`.second`.
Warm-ups: frequency count, find a target, count target occurrences.
Main problems:

3. Valid Anagram — **Green**
4. Two Sum — **Green**

## Day 3 — Frequency Patterns  ⬅️ next

Learn: majority counting, sorting vs hashing, Boyer–Moore Voting Algorithm, two-pass frequency problems.
Main problems:

5. Majority Element
6. First Unique Character in a String

Revision: Contains Duplicate · Valid Anagram · Two Sum

## Day 4 — Strings and Two Pointers

Learn: string indexing, character traversal, `isalnum`, `tolower`, left/right pointers.
Warm-ups: print characters, count vowels, reverse a string, basic palindrome check.
Main problems:

7. Valid Palindrome
8. Is Subsequence

## Day 5 — Right-to-Left and Prefix/Suffix

Learn: reverse traversal, maximum to the right, prefix values, suffix values, building results without nested loops.
Main problems:

9. Replace Elements with Greatest Element on Right Side
10. Product of Array Except Self

## Day 6 — Revision and Mixed Practice

Re-solve: Concatenation of Array · Contains Duplicate · Valid Anagram · Two Sum · Majority Element · Valid Palindrome.
Optional unseen: Intersection of Two Arrays · Ransom Note · Single Number. (No more than two new problems.)

## Day 7 — Weekly Test and Review

One easy in 20 min · one medium in 35–40 min · re-solve two Yellow problems · explain four problems aloud · update tracker · review mistakes and complexity.
